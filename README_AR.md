# خبير AI — إصدار الاتصال المباشر بـ Claude (بدون خادم)

## بناء APK
1. ارفع محتويات هذا المجلد إلى مستودع GitHub جديد، مع الاحتفاظ بمجلد `.github`.
2. افتح تبويب Actions وشغّل `Build Khabeer AI APK`.
3. بعد نجاح البناء، نزّل Artifact باسم `Khabeer-AI-APK`.

## تشغيل التطبيق
- افتح التطبيق وأدخل مفتاح Claude API في خانة «مفتاح Claude API».
- اكتب سؤالك أو أضف نص الدرس وأنشئ الامتحان.
- لا يحتاج هذا الإصدار إلى نشر مجلد server أو إدخال رابط خادم.
- يجب توفر اتصال بالإنترنت ومفتاح API صالح، وقد تُحتسب رسوم حسب استخدام حساب Anthropic.
- المفتاح لا يُحفظ بعد إغلاق التطبيق؛ أدخله عند فتح التطبيق مرة أخرى.

## تنبيه أمان
لا تضع مفتاحًا حقيقيًا داخل ملفات المشروع أو GitHub. إدخال المفتاح في التطبيق أكثر أمانًا من تضمينه في الكود، لكنه يظل مستخدمًا على الجهاز أثناء التشغيل. لا تشارك APK أو المفتاح مع الآخرين. المفتاح الذي سبق نشره في محادثة ينبغي إلغاؤه وإنشاء مفتاح جديد.

## ملاحظات
هذا الإصدار ينفذ الأسئلة النصية وإنشاء امتحان من نص الدرس عبر Claude API مباشرة. لا يتضمن حاليًا استخراج النص من الصور أو PDF أو Word، ولا تصدير PDF.
